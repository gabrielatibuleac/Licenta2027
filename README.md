# Licenta

A university course management application with a React frontend and an ASP.NET Core Web API.

## Current Features

### Backend API
- User registration and login.
- JWT-based authentication and a protected endpoint for retrieving the current user's profile.
- Role-based access for students and professors.
- Professors can create courses with unique access codes.
- Authenticated users can view their courses.
- Students can enroll in courses using an access code.
- Course and user data are stored in PostgreSQL using Entity Framework Core.

### Frontend
- React, TypeScript, and Vite starter application.
- The frontend is not yet connected to the backend API.

## Technology Stack

- React
- TypeScript
- Vite
- ASP.NET Core Web API (.NET 10)
- Entity Framework Core
- PostgreSQL
- JWT authentication

## Requirements

- Node.js and npm
- .NET 10 SDK
- PostgreSQL
